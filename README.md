# MobESP

**A Minecraft Fabric mod that makes mobs glow through walls, allowing players to see any mob type even when hidden behind blocks.**

## Features

- **ESP Glow Effect**: See mobs through walls and terrain with bright outlines
- **Individual Mob Toggles**: Enable/disable ESP for specific mob types
- **Master Toggle**: Instantly turn all ESP on/off with `M` key
- **Smart Search**: Find and filter mobs quickly in the config menu
- **Complete Mob Support**: Works with all hostile, neutral, passive, and boss mobs
- **Mod Menu Integration**: Easy configuration access

## Installation

1. Install [Fabric Loader](https://fabricmc.net/) and [Fabric API](https://modrinth.com/mod/fabric-api)
2. Download required dependencies: [Cloth Config](https://modrinth.com/mod/cloth-config) and [Mod Menu](https://modrinth.com/mod/modmenu)
3. Place MobESP in your `mods` folder

## Controls

- **M**: Toggle ESP on/off
- **O**: Open configuration screen

## Requirements

- Minecraft 1.21.6
- Fabric Loader
- Fabric API, Cloth Config API, Mod Menu

Perfect for players who want enhanced mob awareness and tactical advantages in survival, exploration, or building projects.
